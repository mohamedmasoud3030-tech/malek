# MALEK asset contract

| Surface | Canonical source |
|---|---|
| Login lockup | `/malek-lockup.svg` |
| Expanded navigation | shared brand component using `/malek-mark.svg` + `APP_BRAND_NAME` |
| Collapsed navigation | `/malek-mark.svg` |
| PWA vector icon | `/malek-mark.svg` |
| PWA vector maskable icon | `/malek-maskable.svg` |
| PWA raster icons (install) | `/malek-icon-192.png`, `/malek-icon-512.png` |
| PWA raster maskable icons | `/malek-maskable-192.png`, `/malek-maskable-512.png` |
| Apple touch icon | `/malek-apple-touch-180.png` |
| Visible English name | `MALEK` |
| Arabic name | `مالك` |
| Arabic tagline | `كل أملاكك في مكان واحد` |

Raster PWA icons are generated from the canonical SVG mark/maskable artwork so iOS Safari and Android install surfaces receive PNG sizes they require. The legacy `icon-rentrix-*`, `icon-malik-*`, and `icon-maskable-*` files remain only as historical compatibility artifacts and must not be wired into any visible runtime surface.
