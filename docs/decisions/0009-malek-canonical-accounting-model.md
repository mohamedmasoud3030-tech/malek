# 0009. Malek canonical accounting and contract-rights model

## Status

**SUPERSEDED AS A NORMATIVE SOURCE — HISTORICAL RECORD ONLY**

هذا ADR يحتفظ بسياق القرارات المحاسبية الأولية التي سبقت تثبيت دستور منطق الأعمال والعقود. لا يجوز استخدامه بعد الآن كمصدر مستقل لتغيير سلوك المنتج.

المصدران الملزمان حاليًا هما:

- `docs/business/CANONICAL_BUSINESS_AND_CONTRACT_RULES_AR.md`
- `governance/canonical-business-rules.json`

أي تعارض بين هذا السجل التاريخي وبين الدستور المقفل يُحسم لصالح الدستور المقفل.

## Historical context

كان المشروع يمتلك بنية GL وRPCs مالية متقدمة، لكنه لم يكن قد ثبّت بصورة واحدة نهائية العلاقة بين المكتب والمالك والمستأجر، أو طريقة تشغيل العقار، أو دورة العقد وجدول الاستحقاقات. لذلك أنشأ هذا ADR خطًا محاسبيًا أوليًا يفصل بين:

1. القرار التشغيلي.
2. الترجيح المحاسبي.
3. القرار القانوني أو الضريبي الذي يحتاج عقدًا فعليًا أو مراجعة مختص.

## Historical decisions retained

### property_management

- المكتب وكيل.
- العرض المحاسبي NET.
- كامل الإيجار ليس إيرادًا للمكتب.
- إيراد المكتب هو العمولة أو الرسم المستحق له.
- `OWNER_IS_CREDITOR` هو الوضع الافتراضي لإدارة الغير، مع تخزين `collection_role` صراحة في الاتفاقية.

### master_lease

- نشاط مستقل عن إدارة أملاك الغير.
- المكتب أصيل تجاه المستأجر الفرعي.
- الالتزام تجاه المالك قد يستمر رغم الخواء.
- أصل حق الاستخدام، التزام الإيجار، الفائدة، الإهلاك والتعديلات تحتاج وحدة مستقلة.
- لا يستخدم Owner Settlements بدل محاسبة الإيجار الرئيسي.

### GL وSubledgers

- GL مصدر القوائم المالية.
- العقود والفواتير والودائع والتسويات وRent Roll دفاتر مساعدة تشغيلية.
- كل دفتر مساعد مالي يُصالح مع حساب الرقابة المقابل.

### OMR precision

- العملة الحالية OMR.
- التخزين والترحيل النهائي بثلاث خانات عشرية.
- وحدة التقريب 0.001 OMR.
- التقريب النهائي مرة واحدة خادميًا.
- الواجهة ليست مصدر الحقيقة النهائي للمبالغ.

### المصروفات والمقاصة

- مصروف المكتب مصروف تشغيلي للمكتب.
- مصروف المالك `Due from Owner`، وليس مصروفًا للمكتب.
- مصروف المستأجر مطالبة أو فاتورة استرداد واحدة دون تكرار الذمة.
- المقاصة لا تُفترض دون حق تعاقدي صريح.

### التأمينات

- التأمين التزام تجاه المستأجر حتى يُرد أو يُستخدم وفق العقد.
- خصم المتأخرات يخصص لفواتير حقيقية.
- تعويض التلفيات يذهب للمستفيد الاقتصادي المحدد في العقد.

### الاتفاقيات التاريخية

- لا تعديل صامت على اتفاقية مستخدمة.
- كل تعديل جوهري ينشئ Version أو Amendment جديدًا.
- لا تُعاد كتابة قيود أو تسويات تاريخية.

## Implementation gates retained

يمكن تنفيذ إصلاحات الأمان التي لا تغيّر نموذج القيد، ومنها:

- عزل الشركات.
- منع تكرار عناصر التسوية.
- إعادة التحقق قبل الاعتماد والدفع.
- إغلاق الكتابة المالية المباشرة.
- سلامة سلسلة migrations.

ولا يبدأ Backfill أو إعادة تصميم القيود إلا وفق ترتيب التنفيذ المثبت في الدستور المقفل.

## Supersession rule

أي تعديل مستقبلي على القرارات السابقة لا يتم في هذا الملف. يجب أن يتم عبر:

1. ADR جديد أو ADR يستبدل قرارًا سابقًا صراحة.
2. رفع `schema_version` في العقد الآلي.
3. تحديث Changelog والبصمة.
4. موافقة مالك المنتج.
5. نجاح `Canonical Business Rules Guard`.
