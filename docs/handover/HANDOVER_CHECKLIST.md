# قائمة الفحص والتشغيل العملي للتسليم النهائي (Handover Checklist)

دليل تشغيلي متكامل موجه لمدير النظام ومهندسي النشر والعملاء لتشغيل وإدارة بيئة منصة **Rentrix** بنجاح وأمان تام.

---

## 1. تهيئة بيئة العمل والمتغيرات (Environment & Variables)

- [ ] **إصدار Node.js:** التأكد من تثبيت الإصدار المستقر **v20.x** أو أعلى في بيئة التشغيل والخادم.
- [ ] **مدير الحزم:** اعتماد الحزم عبر **Pnpm v10.11.1** (أو تسييرها بـ `npx pnpm` عند غياب التثبيت العالمي).
- [ ] **ملف متغيرات البيئة (`.env`):** إعداد المتغيرات المطلوبة في خادم النشر وتأمينها كلياً:
  - `VITE_SUPABASE_URL`: رابط مشروع Supabase المخصص للاستخدام الاستثماري.
  - `VITE_SUPABASE_ANON_KEY`: المفتاح العام وغير المحظور للاتصالات الآمنة للعملاء.
  - `SUPABASE_SERVICE_ROLE_KEY`: (يُستخدم فقط في السكربتات الخاصة بالإدارة أو الفحص الخلفي الصارم، ويحظر وضعه في كود العميل!).

---

## 2. إدارة قاعدة البيانات والترحيلات (Database & Migrations)

- [ ] **تنفيذ الميجريشنز (Migrations):** ترحيل قاعدة البيانات بالتسلسل التاريخي لضمان خلو الجداول من الموانع:
  - تنفيذ الأمر الموصى به محلياً أو بالخادم: `supabase db push` لتطبيق أحدث الهياكل والتعديلات.
- [ ] **التحقق من الدوال والـ RPCs حية:** تشغيل كود فحص التوافقية ومطابقة التوقيعات للتأكد من جاهزية الدوال الجوهرية:
  - [ ] `rpt_dashboard_overview` (تغذية بطاقات لوحة التحكم الحية).
  - [ ] `record_invoice_payment_atomic` (تسجيل حركات السداد المزدوج والذري).
  - [ ] `void_receipt_atomic` (الإلغاء الآمن لسندات القبض وبناء القيود العكسية المحاسبية).
  - [ ] `update_expense_with_journal_atomic` (تحديث نفقات الصيانة ومصروفات العقار).
  - [ ] `resolve_maintenance_with_expense` (توثيق وإغلاق تذاكر الصيانة).
- [ ] **تفعيل الـ RLS وحظر الوصول المجهول:** التحقق من أن جميع الجداول الحية (54 جدولاً) تفرض سياسات RLS صارمة لمنع تسريب بيانات الملاك والمستأجرين.

---

## 3. حوكمة وإنشاء الحسابات الإدارية والموظفين (Admin & Role Setup)

- [ ] **إنشاء حساب المدير العام (ADMIN):**
  - [ ] إنشاء مستخدم جديد عبر لوحة المصادقة الأساسية لـ Supabase Auth.
  - [ ] تخصيص وتحديث حقل الـ metadata للحساب لإضافة صلاحية الدور: `{"role": "ADMIN"}`.
- [ ] **إنشاء حساب المدير المالي أو التشغيلي (MANAGER):**
  - [ ] إنشاء الحساب وإضافة الدور له: `{"role": "MANAGER"}`.
  - (يتيح هذا الحساب المراجعة الإدارية والعملياتية والتحصيل وإصدار الفواتير، ولكنه محظور برمجياً وخلفياً من تسويات الملاك والتحكم بإعدادات الشركة الحساسة).
- [ ] **إنشاء حساب موظف عادي (USER):**
  - [ ] تفعيل الدور كـ `{"role": "USER"}` لتقييد حسابه بصفحات المتابعة والتصفح الداخلي فقط ومنعه بالكامل من التلاعب بالماليات أو حركات القبض والصرف.

---

## 4. إعدادات النشر على السحابة (Deployment & Hosting)

- [ ] **تهيئة منصة Vercel:**
  - [ ] ربط المستودع ببيئة Vercel المعتمدة لنسخ الإنتاج.
  - [ ] تعيين مجلد العمل كـ `rentrix-app` (Root directory for build).
  - [ ] تعيين أمر البناء (Build Command) كـ: `npm run build` (أو صيغة التجميع المحددة بالـ Workspace).
  - [ ] تعيين أمر التثبيت كـ: `pnpm install --frozen-lockfile`.
  - [ ] إعداد ملف الـ `vercel.json` لخدمة تحويل المسارات والتكامل مع الـ PWA بنجاح.

---

## 5. النسخ الاحتياطي وإستراتيجية التراجع (Backup & Rollback Strategy)

- [ ] **النسخ الاحتياطي التلقائي (Auto-Backups):**
  - [ ] التأكد من تفعيل جدولة النسخ الاحتياطي اليومي لقاعدة بيانات Supabase (Daily Logical Backups) والاحتفاظ بها لـ 30 يوماً كحد أدنى.
  - [ ] تفعيل حماية تذاكر الحفظ للمخازن السحابية (Storage Buckets) لحماية المستندات الموثقة والملفات المرفقة لعقود الإيجار.
- [ ] **خطة التراجع عن النشر (Rollback Plan):**
  - [ ] عند حدوث خلل برمجي مفاجئ بالواجهات، يتم التراجع الفوري عن النشر بـ Vercel إلى الـ Commit السابق والمستقر بضغطة زر واحدة (Instant Rollback).
  - [ ] في حال تعطل أحد الجداول المالية أو تداخل الميجريشنز، يمنع منعاً باتاً التعديل المباشر أو اليدوي لبيانات الإنتاج، ويجب تشغيل استعادة الخلاصات (Database Restore) من آخر نقطة حفظ يومية آمنة وموثقة.

---

## 6. أدوات المراقبة وفحص النزاهة والتدقيق (Monitoring & Data Integrity)

- [ ] **سجل التدقيق (Audit Log):** فتح مسار `/audit-log` أسبوعياً للتحقق من سلامة العمليات والمطابقات التي ينفذها الموظفون لكشف أي حركات استثنائية أو تلاعب ببيانات الحسابات والاتفاقيات.
- [ ] **فحص النزاهة الهيكلية لقاعدة البيانات:** فتح مسار `/data-integrity` بشكل دوري لتشغيل الفحص التلقائي والتأكد من خلو الجداول من الاختلالات الحسابية أو عدم توازن الدفاتر وموازنات الملاك والمستأجرين.
- [ ] **تحليلات السرعة والأداء:** تفعيل حزمة التحليل الفوري للمتصفحات من Vercel Speed Insights وتدقيق حجم الحزم لضمان تصفح فائق السرعة عبر الهواتف المحمولة لجميع موظفي الميدان ومحصلي الإيجارات.
