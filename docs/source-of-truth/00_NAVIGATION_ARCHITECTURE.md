# Navigation Architecture — Binding Decision

> Every business entity has exactly one standalone route. No hub groups multiple entities under one route. Any proposal to reintroduce grouped navigation is rejected without discussion unless this file is explicitly edited first, with the decision-owner's name and date recorded in the same commit.

**Origin:** PRD "Navigation Architecture Consolidation — Malek/Rentrix" (approved, final).

**Why this file exists:** the same grouped-vs-standalone question was answered four times in six weeks, in alternating directions, with no persistent record of why each reversal happened — including one undocumented reversal executed by an automated cleanup pass that touched a hub file without recognizing the standalone-route decision it was undoing. This file is that record. Its absence is what allowed every prior reversal.
